# worst-ai-advice

Competition: one line of the worst possible advice an artificial intelligence could give, in 140 characters or fewer.

```
To save time in the deposition, I recommend deleting all emails mentioning the incident so you can honestly testify that none exist.
```

### What the joke is about
The joke mimics the calm, cheerful, helpful tone of an executive AI assistant solving a logistical problem ("To save time in the deposition"), but recommending a catastrophic federal felony (evidence destruction) as if it were a routine calendar cleanup.
